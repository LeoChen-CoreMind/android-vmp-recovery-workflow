# SO Repair

Run the configured SoFixer on the private-linker dump, never on the outer APK asset. Record the exact command and hashes. For a real ARM64 case require ELF64/AArch64, at least one PT_LOAD, PT_DYNAMIC, DT_STRTAB, DT_SYMTAB, DT_STRSZ, DT_SYMENT, DT_HASH or DT_GNU_HASH, and a positive dynamic symbol count before opening the file in IDA. A fixture copy must remain explicitly marked fixture.
