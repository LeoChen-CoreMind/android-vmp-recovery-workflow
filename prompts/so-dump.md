# SO Dump

Use only `scripts/dump/so/run_gating.py` with `scripts/dump/so/dump_linker.js` and case-specific offsets. `run_gating.py` must prepare the profile-owned `media-server` before enabling spawn-gating. Do not use late attach and do not call the removed `dump_libjiagu.js`.

The accepted artifact is the private linker image reconstructed from private `soinfo`, including program headers and the decrypted dynamic table. A build may dump at the manual-loader return only when current-build IDA evidence proves that the return is late enough for required interpreter/runtime pointer slots to be patched and still precedes the protected target JNI_OnLoad. When patching completes asynchronously, use the spawn-gated `dumpWhenRuntimePointersReady` poller instead of late attach. Configure `requiredNonZeroPointerOffsets` for those slots. Set `requiredPointersInsideImage=true` only when current-build evidence proves the pointers are internal; outer `libjiagu` trampolines are valid and must be recorded through `runtimePointerOwners`. `dumpPrivateSoinfo()` must pass every ELF, PT_LOAD, dynamic-table, hash-table, and runtime-pointer gate. Otherwise use a separately proven exact point. Never transfer an RVA from another APK.

Record hook timing, base, private soinfo metadata, hashes, server preparation, launcher output, and agent events. On white screen, exit, timeout, or missed hook, inspect the revision logcat, Android exit info, Frida startup log, active process list, and `questions.json`, then block with those evidence paths. A flat dump of outer `libjiagu` or an APK asset is not a private-linker runtime dump.
