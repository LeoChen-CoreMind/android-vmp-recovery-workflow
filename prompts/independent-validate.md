# Independent Validation

Validate every restored DEX independently from the restoration code: magic/header size/endian, file size, SHA-1, Adler32, map_list bounds, output hashes, and repair-manifest coverage. For a real restoration, require Android SDK `dexdump -f` and Java-backed JADX to accept every output; store complete commands, return codes, stdout, and stderr under `reports/`. If JADX default restructuring reports partial errors, do not hide them: require the error count and error-method set to exactly match the source DEX baseline, require no recovered method in that set, and require JADX fallback mode to exit successfully. Missing Java, JADX, or dexdump is a recoverable blocking question, not a skipped check.

Run repeatability validation and require a second restoration from the same inputs/config to produce identical restored DEX hashes. Report changes in runtime SO, IDA, and simulation evidence separately because ASLR-bound addresses and binary hashes may legitimately differ between device launches. Fixture pass-through is explicitly `orchestration-only` and does not prove customer VMP restoration.
